# موقع مدرسة ذكور قيرة الثانوية

موقع تعريفي بمدرسة ذكور قيرة الثانوية، جاهز للاستضافة مباشرة على **GitHub Pages**.

## محتويات المجلد

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية للموقع |
| `logo.jpg` | شعار المدرسة |
| `cover.jpg` | صورة خلفية القسم الرئيسي (Hero) |
| `gallery-1.jpg`, `gallery-3.jpg`, `gallery-4.jpg` | صور ألبوم المدرسة |
| `anthem.mp3` | نشيد المدرسة |
| `.nojekyll` | يمنع GitHub من معالجة الملفات عبر Jekyll |

## طريقة رفع الموقع على GitHub Pages

### 1. أنشئ مستودعًا (Repository) جديدًا على GitHub
اذهب إلى https://github.com/new وأنشئ مستودعًا جديدًا (يمكن تسميته مثلاً `qira-school`).

### 2. ارفع الملفات
من صفحة المستودع اضغط **Add file → Upload files**، ثم اسحب كل ملفات هذا المجلد (بما فيها `.nojekyll`) وارفعها، ثم اضغط **Commit changes**.

أو عبر سطر الأوامر (Git):
```bash
git init
git add .
git commit -m "نشر موقع المدرسة"
git branch -M main
git remote add origin https://github.com/USERNAME/qira-school.git
git push -u origin main
```

### 3. فعّل GitHub Pages
1. من صفحة المستودع، اذهب إلى **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت **Build and deployment → Source** اختر **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/ (root)**، ثم اضغط **Save**.

### 4. افتح الموقع
بعد دقيقة أو دقيقتين، سيظهر رابط الموقع في نفس الصفحة بالشكل التالي:
```
https://USERNAME.github.io/qira-school/
```
افتح هذا الرابط من أي جهاز ومتى شئت — الموقع سيبقى منشورًا ومجانيًا طالما المستودع موجود.

## ملاحظات
- تم التأكد من أن جميع الروابط للصور والصوت داخل `index.html` تُشير إلى ملفات موجودة فعليًا في هذا المجلد (تمت إزالة إشارة لصورة `gallery-2.jpg` غير موجودة).
- إن أردت إضافة صور جديدة لاحقًا، ضعها في نفس المجلد وأضف لها `<figure>` جديدة داخل قسم "ألبوم الصور" في `index.html`.
- الملفان `cover.jpg` و`anthem.mp3` كبيرا الحجم نسبيًا؛ يمكن ضغطهما مستقبلاً لتحسين سرعة تحميل الموقع.
